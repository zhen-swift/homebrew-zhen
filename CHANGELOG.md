# Changelog

Each entry names the zhen-core release the formula installs. zhen's own changes are in
[zhen-core's changelog](https://github.com/zhen-swift/zhen-core/blob/main/CHANGELOG.md).

## Unreleased

- zhen 0.8.1, which runs on macOS 15.6 and later, so the formula now installs on Sequoia.
- zhen 0.8.0, built from the git tag rather than the tarball, so `zhen --version` names
  its commit. `brew test` checks that it does.
- zhen 0.7.0, built from source. Installs `zhen` and its manual page.
